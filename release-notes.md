# Release-Notizen

Jede Zeile, die mit "- " beginnt, erscheint im Update-Hinweis des Launchers.
Vor jedem Release anpassen, dann Version erhöhen und pushen.

- Neu: Seite „Neuigkeiten“, oben in der Navigation unter „News“
- News von Savira, Artikel von minecraft.net und die Java-Patchnotes von Mojang an einem Ort, live geladen
- Filter nach Art (News, Patchnotes, Changelog) und Quelle (Savira, Minecraft, Mojang), dazu eine Suche
- Ganze Artikel und Patchnotes direkt im Launcher lesen, Minecraft-Artikel auch auf minecraft.net öffnen
- Changelog mit allen Savira-Versionen
